后端工具箱

这里集中放置排障和迁移工具：恢复全局轮询、重置停止账号、立即轮询、复制自检报告、打开状态接口。

完整后端备份 / 恢复

完整备份会包含 config、accounts、ignored-mails，其中 accounts 含 QQ 邮箱授权码。请只保存在自己的可信设备上。

建议的日常使用流程

  • 账号异常：先到“运行日志”看错误，再到“账号管理”测试账号。
  • 修复授权码后：点“一键修复并轮询”，不用逐个重置。
  • 换电脑迁移：使用“导出完整备份 / 导入完整备份”。
  • 界面不适合当前环境：右上角切换后端 GUI 主题、字体和密度。

Windows 托盘程序

v2.1 新增 Electron 托盘模式。托盘程序启动后会在系统托盘显示图标，右键可打开后端设置、查看状态、重启后端或退出。

开发/自用运行

  1. 进入 backend 文件夹。
  2. 运行 start-tray-windows.bat。
  3. 或者命令行运行 npm install && npm run tray。

打包托盘 EXE

  1. 在 Windows 上进入 backend 文件夹。
  2. 运行 build-windows-tray.bat。
  3. 生成 dist\QQ邮箱提醒托盘版-2.9.0.exe 后双击运行。

当前沙盒不是 Windows，无法实际生成并验证 Windows 托盘 exe；项目已包含 Electron 托盘入口和构建脚本，你在 Windows 上运行脚本即可构建。

说明

  • 保存账号前可以点击“测试”验证邮箱和授权码是否能连接 QQ IMAP。
  • 导入/导出用于换电脑迁移；导出文件包含授权码，请勿分享。
  • 本地忽略不会把服务器邮件标为已读，只影响本工具显示。
