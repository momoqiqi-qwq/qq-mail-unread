QQ邮箱多账号未读提醒 v2.9 优化版快速开始

1. 启动后端
   cd backend
   npm install
   npm start

2. 打开后端管理 GUI
   http://127.0.0.1:8765/admin/

3. 在“账号管理”里新增 QQ 邮箱账号。
   可先点“测试”验证授权码是否可用，再保存账号。
   注意：授权码是 QQ 邮箱 IMAP/SMTP 服务授权码，不是 QQ 登录密码。

4. 安装 Chrome 扩展
   打开 chrome://extensions/
   开启开发者模式
   加载已解压的 chrome-extension 文件夹

5. 本版优化点
   - 验证码识别更准确，避免把 expires in 10 minutes 误当验证码。
   - 默认特大字体、最大弹窗和舒适界面。
   - 邮件列表新增“标为已读”，会真正修改 QQ 邮箱服务器上的已读状态。
   - “本地忽略”仍只影响本工具显示，不改变服务器状态。

6. 换电脑迁移账号
   后端 GUI -> 账号管理 -> 导出账号 / 导入账号
   导出文件包含授权码，请妥善保管。

7. 清理旧验证码
   后端 GUI -> 本地忽略 -> 选择时间 -> 清理旧验证码

8. Windows 托盘模式
   自用运行：双击 backend/start-tray-windows.bat
   打包托盘 exe：在 Windows 上运行 backend/build-windows-tray.bat
