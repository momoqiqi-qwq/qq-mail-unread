隐私建议

如果经常投屏或在公共场合使用，建议开启隐私模式，并关闭“通知中显示发件人和主题”。v2.2 支持更准确的验证码识别、界面直接标为已读、默认特大字体/最大弹窗、11 套主题、账号测试、账号导入导出、一键清理旧验证码和 Windows 托盘模式。经常投屏或在公共场合使用时，建议关闭“显示正文预览”，并开启隐私模式。

如何启动本地后端

进入完整项目包的 backend 目录，运行：

npm install
npm start

如何配置 QQ 邮箱授权码

  1. 登录 QQ 邮箱网页版。
  2. 进入“设置 / 账号与安全”，找到 POP3/IMAP/SMTP 服务。
  3. 开启 IMAP/SMTP 服务。
  4. 按页面提示生成 16 位授权码。
  5. 打开 http://127.0.0.1:8765/admin/ 的“账号管理”，新增账号并填写授权码。
  6. 重启后端。

注意：authCode 是 QQ 邮箱 IMAP/SMTP 服务授权码，不是 QQ 登录密码。

安全与隐私

  • 后端只监听 127.0.0.1，不会对公网开放。
  • 扩展只访问 http://127.0.0.1:8765/*。
  • v2.2 可调节扩展弹窗尺寸、字体大小和主题，并可打开独立面板窗口；独立面板可直接拖拽窗口边缘调整大小。
  • v2.2 可在扩展设置和后端设置 GUI 中调节正文预览比例；账号导出文件会包含授权码，请妥善保管。
  • QQ 授权码只保存在本机 accounts.json。
  • 连续轮询失败达到后端配置的 maxConsecutiveFailures（默认 15 次）后，该账号会自动停止轮询；修复后可在后端 GUI 重置。
  • “一键清理旧验证码”只做本地忽略，不会把 QQ 邮箱服务器上的邮件标为已读；Popup 中的“标为已读”会真正修改服务器状态。
